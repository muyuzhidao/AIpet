错误态

需要明确区分错误类型

错误必须指向可处理原因，不只显示“失败”。

错误 页面表现 用户可做什么
全部更新失败 精选、全部宠业动态、AI 日报都保留旧数据，顶部红色提示 查看数据源页失败原因，重新更新
API key 失效 数据源页标红，显示失效来源 更新 key 或关闭该来源
Tavily 超限 独立站和新闻来源暂停 等待额度恢复或降低关键词组数量
定向抓取失败 该网站状态为失败，记录 HTTP 状态或解析错误 检查网址、选择器、访问频率
边界情况

长文本和大量数据

保证信息密度，但不让文本挤压布局。

边界 处理规则
超长标题 精选卡片和动态卡片显示 2 行，AI 日报里完整显示
超长原文 详情页默认展示关键片段，支持展开
长 URL 显示域名和路径摘要，完整链接放在 hover/title 或复制操作中
大量动态 全部宠业动态分页或虚拟滚动，每次显示稳定高度卡片
重复主题 精选区按主题聚合，保留多个来源作为证据链；全部动态区保留原始时间序

交互规则

行为映射表

前端实现时按表格覆盖主要操作。

触发 用户操作 系统行为 反馈
用户 点击“开始更新” 创建更新任务，依次调用数据源，生成全量动态，再重算精选和 AI 日报 进入加载态，完成后 Toast 汇总
用户 点击精选卡片 展开当前卡片的推荐理由和标签信息，保留时间流位置 卡片高亮，推荐理由可见
用户 切换到“全部宠业动态” 滚动到全量时间流模块，不重新抓取 模块高亮，页面保持当前位置上下文
用户 打开“AI 日报” 跳转到日报模块，展示当日结论和章节卡片 日报模块进入视口
用户 筛选来源或标签 过滤当前内容流，不重新抓取 列表刷新；无匹配进入筛选无结果态
系统 部分来源失败 继续处理成功来源，记录失败来源 顶部显示部分可用，精选和日报带缺失说明
系统 全部来源失败 保留旧数据，不生成新版内容流 错误 Toast，首页显示失败提示
异常 API key 失效 停止该来源，其他来源继续 数据源页标红，Toast 给出具体来源
异常 Tavily 超限 停止 Tavily 相关独立站和新闻检索 警告 Toast，记录额度错误
