## 今日完成：真实数据闭环达成（第 1–5 步）
从纯静态原型升级为「抓取 → 规范化 → AI 分析 → 页面真实呈现」的完整闭环。每天 `npm run update` 刷新一版真实机会情报，页面无需改动自动切换。

## 技术架构
- `lib/types.ts`：统一数据结构。视图模型(FeaturedStory/NewsItem/ReportCard/TopTopic/SourceStat/DailySection)+ 规范结构(RawItem/Opportunity，含 4 维评分 ScoreBreakdown、机会池状态、证据 EvidenceRef)+ 运行日志 UpdateRun。
- `lib/store.ts`：页面唯一取数入口。读 `data/snapshot.json`，**按字段浅合并种子**(管线没产出的字段回退 `lib/seed.ts`)；用 React cache 包裹避免重复读盘。
- `lib/seed.ts`：出厂种子(原静态 mock)，快照文件缺失/损坏时兜底。
- `lib/sources/*`：各源抓取 → RawItem[]（redfox=抖音、tavily、grok=X、reddit 未启用）。
- `lib/pipeline/normalize.ts`：RawItem → NewsItem 视图，按来源给展示标签。
- `lib/pipeline/analyze.ts`：DeepSeek 分析，产出机会(评分+理由+证据)与日报；今日热点、来源计数、日报数字由代码从真实数据派生(不让 AI 编)。
- `lib/ai/deepseek.ts`：DeepSeek(OpenAI 兼容)调用封装，response_format json_object。
- `scripts/update.ts`：`npm run update` 编排。某源或 AI 失败都不阻断其余(部分可用)；AI 失败时 featured/日报回退种子。
- 三个页面 force-dynamic，改 snapshot 刷新即生效。`data/snapshot.json`、`raw-*.json` 是产物，已 gitignore。跑 TS 脚本用 tsx + dotenv(devDep)。

## 数据源接入（凭证在 .env，已 gitignore，此处只记变量名）
- **抖音**(国内主力)：RedFox API，header `REDFOX_API_KEY`。`POST https://redfox.hk/story/api/dyData/searchArticle`，body `{keyword,offset,sortType}`，返回 `code:2000` + `data.list`。8 个宠物关键词，单次约 160 条。小红书/公众号是 RedFox 另外的端点，待用户给接口示例。
- **Tavily**(新闻/独立站)：`TAVILY_API_KEYS`(逗号分隔多 key 故障切换)。topic=general 语义搜索 + 宠物词过滤(避开汽车等泛新闻)。约 50 条。
- **X**(Grok)：`GROK_BASE_URL` + `GROK_API_KEY`(第三方代理 jiuuij.de5.net)。model `grok-4.20-multi-agent-high`。能取真实 X 帖(带 x.com 链接)，质量高，但单次百万级 token、偶发 429(代理账号池空)。用户确认包月不限量、进每日更新。约 8 条。
- **DeepSeek**(AI 分析)：`DEEPSEEK_API_KEY`，base `https://api.deepseek.com`，model `deepseek-v4-flash`(注意全名，不是 v4-flash；另有 deepseek-v4-pro)。
- **Reddit**：代码就绪(`lib/sources/reddit.ts`)但**未启用**——用户给的 secret 是 n8n 空值占位 `__n8n_BLANK_VALUE_*`，public `.json` 被 403，需真 client secret 走 OAuth；已从 update 编排移除。client_id 真实存在 .env。

## 经验 / 踩坑
- RedFoxHub 是数据采集 API 市场(技能/文档/API Key/playground)，正路是 API Key + header 认证，不要借网页 cookie(会过期、还需 sessionStorage 的 api_token)。
- 抖音作品正文常为空，标题是 `#标签` 堆砌、信息密度低；但互动数(赞/评/藏)和评论热词已存进 RawItem，是 AI 判断机会强弱的关键输入。
- AI 分析质量好：能跨平台识别缺口(如低尘猫砂：X/独立站提痛点 + 抖音有需求但专注供给少 → 89 分)，单次产出 10 个机会、评分有梯度(68–94)。
- 中文文案标点要保留全角；改文件时别把全角逗号/冒号误改成半角。
